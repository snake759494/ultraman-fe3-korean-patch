# 울트라맨 파이팅 에볼루션 3 (SLPS-25441) 한글패치 계획

## 1. 디스크·데이터 구조 (분석 완료)
| 항목 | 내용 |
|---|---|
| 디스크 | DVD ISO(2048B 섹터). 데이터는 `FILE1~4.BIN` 네 덩어리 |
| 파일 색인 | 실행파일 `SLPS_254.41` 파일오프셋 `0x214f98`, 16B × 3,552개 `[오프셋, 할당크기, 실제크기, FILE번호(0~3)]`. 코드가 항목 번호로 읽음 |
| FUM | 이름 붙은 묶음 `FUM\0`, 개수, 0x80B 항목 `[이름 0x74][오프셋][할당][크기]`. 마지막 멤버는 색인의 '실제크기'를 넘으므로 할당크기로 읽어야 함 |
| DFS | `DFS\x01`, u32 풀린크기, u32 압축크기 + 오쿠무라 LZSS(링 4096, 시작 0xFEE, 플래그 LSB 1=리터럴). 재압축기 작성·왕복 검증 완료 |
| POM | 텍스처. 0x40 헤더: h[1]=높이, h[2]=폭, h[3]=버전(5~7)\|모드<<16, h[6]=색수\|(팔레트수-1)<<16, h[8..9]=GS TEX0. 모드0: 팔레트 0x40, 픽셀 선형(행 간격=폭). 256색 팔레트는 CSM1 스위즐, 알파 0~0x80 |
| 글자 | **실행파일·데이터에 문자열 텍스트가 없음 — 화면의 일본어는 전부 POM 그림** |
| 동영상 | `ipum`(IPU) 166개 (FILE2, FILE3) |

## 2. 글자 그림 목록 (조사 완료, 약 350장)
- 미션: `misn_detail01~20`(설명판), `misn_title01~20`(제목, 폭 512 초과분은 GS 페이지 규칙으로 64행 아래에 저장), `misson_bar*`(평가 항목), `hint1~20`
- 캐릭터: `v_*`(프로필 40여 장), `*_h`(필살기 목록), FUM 안 `game_2d/c_*`(이름 배너), `castom/wazasetumei/*_w`(기술 설명), `select/wazamei/*_h`
- 메뉴·시스템: 타이틀 메뉴, 옵션, 메모리카드 메시지, 창(window), 리플레이, 스토리 선택, 버튼 안내 바, 로딩, 결과/랭킹
- 해금 알림 `common_c.act` 98장(가로 반복 감싸기로 좌우가 잘려 저장됨)
- 튜토리얼 `tuto_f_*`, `message*`, `mes_*`, 자막 `zimaku1~8`(모드2 4bpp)

## 3. 한글화 방식
1. 글자 그림마다 영역·원문·번역·양식(글꼴 굵기, 색, 외곽선/광택) 명세 작성 (`translation/images/*.json`)
2. 렌더러: 원문 글자 지우기(배경 복원) → 한글 렌더(NanumSquareNeo 굵기별: 제목 Heavy/ExtraBold, 본문 Bold) → 원래 팔레트로 양자화 → POM에 기록
3. 감싸기 저장 그림(misn_title, common_c)은 논리 화면으로 펼친 뒤 편집하고 다시 접음
4. 재조립: 단독 POM은 같은 크기로 제자리 교체. FUM 멤버는 DFS 재압축 후 FUM 재구성, 할당을 넘으면 FILE3 끝(ISO 끝)에 붙이고 색인 수정 + ISO 레코드 크기 갱신
5. 검증: PCSX2 휴대용 사본으로 실제 화면 확인
6. 동영상: 음성 대사가 있으면 받아쓰기→번역→자막 합성(이전 작업 방식)
